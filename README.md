# Saudi Legal Corpus

مشروع عام ومستقل للأنظمة والمصادر القانونية السعودية فقط.

لا يحتوي هذا المستودع على QADA أو Agent OS أو أي تطبيق آخر. وظيفته أن يكون طبقة بيانات قانونية موثقة يمكن للأنظمة الخارجية قراءتها عبر واجهات مستقلة.

## البنية

```text
Saudi Legal Corpus
│
├── systems/
│   ├── نظام-خدمة-الأفراد/
│   └── ...
├── regulations/
├── decisions/
│   ├── council-of-ministers/
│   ├── royal-orders/
│   └── royal-decrees/
├── judgments-principles/
│   ├── supreme-court/
│   └── board-of-grievances/
├── sources/
│   ├── bureau-of-experts/
│   ├── umm-al-qura/
│   └── official-sources/
├── amendments/
├── verification/
├── schemas/
└── api/
```

## قاعدة المادة النظامية

كل مادة يجب أن تكون قابلة لتتبع:

- النص الحالي الرسمي.
- النص السابق عند وجود تعديل.
- تاريخ النفاذ.
- التعديلات.
- أداة التعديل.
- المصدر الرسمي.
- رابط المصدر.
- تاريخ آخر تحقق.
- بصمة المحتوى.

لا يُعامل أي تفسير أو تلخيص أو استنتاج باعتباره نصًا رسميًا.

## العلاقة مع الأنظمة الخارجية

```text
              Saudi Legal Corpus
                /            \
               /              \
          Agent OS            QADA
      قراءة/تحديث الأدوات   قراءة واستدلال وصياغة
```

Agent OS وQADA مشروعان مستقلان. لا يتم دمج كودهما أو بياناتهما التطبيقية داخل هذا المستودع.
