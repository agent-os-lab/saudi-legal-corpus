# Saudi Legal Corpus

مستودع عام مستقل مخصص للأنظمة واللوائح والقرارات والمراسيم والأوامر والمبادئ القضائية والمصادر الرسمية في المملكة العربية السعودية.

## الهدف

بناء مرجع قانوني منظم وقابل للتحقق آليًا، يحفظ النص الرسمي وسلسلة مصدره وتعديلاته وحالته النظامية دون خلطه مع أي تطبيق أو وكيل ذكاء اصطناعي.

## مبادئ المستودع

- النص الرسمي أولًا.
- كل مادة ترتبط بمصدر رسمي واضح.
- لا تُعد الصياغة التفسيرية نصًا رسميًا.
- حفظ تاريخ الإصدار والنفاذ والتعديل والإلغاء عند توفره.
- حفظ رابط المصدر وتاريخ آخر تحقق وبصمة المحتوى.
- عدم استبدال النص الرسمي بملخص أو إعادة صياغة.
- يمكن لأي مشروع خارجي الاستهلاك من هذا المستودع دون أن يصبح جزءًا منه.

## البنية

- `systems/` — الأنظمة.
- `regulations/` — اللوائح التنفيذية والتنظيمية.
- `decisions/` — القرارات.
- `royal-orders/` — الأوامر الملكية.
- `royal-decrees/` — المراسيم الملكية.
- `judicial-principles/` — المبادئ القضائية المنشورة رسميًا.
- `sources/` — تعريف المصادر الرسمية وبياناتها.
- `amendments/` — سجل التعديلات والنسخ الزمنية.
- `verification/` — سجلات التحقق والبصمات.
- `schemas/` — مخططات البيانات الموحدة.

## ملاحظة

هذا المستودع لا يحتوي على QADA أو Agent OS أو أي تطبيق آخر. هو طبقة بيانات ومصادر قانونية مستقلة فقط.
