# API

واجهة استهلاك مستقلة لـ Saudi Legal Corpus.

الهدف أن تتمكن المشاريع الخارجية مثل QADA وAgent OS من القراءة أو التحقق عبر API دون دمج المستودعات أو خلط قواعد البيانات.

المبدأ:
- القراءة عامة للمحتوى المنشور.
- أي تحديث آلي يجب أن يمر بالتحقق وسياسة المصادر قبل اعتماده.
- API لا يضيف تفسيرًا قانونيًا إلى النص الرسمي.


## عقد القراءة لـ QADA — v1

الملف `api/manifest.v1.json` هو نقطة الاكتشاف الوحيدة للمستهلكات الخارجية.

قواعد الاستهلاك:
- لا يُعامل وجود سجل في المستودع على أنه تحقق قانوني.
- QADA لا يستخدم في توليد الحجة أو الاقتباس القضائي إلا السجل ذي `verification_status=verified` و`qada_eligible=true`.
- الحالات `needs_review` و`partial` و`unverified` تظهر للتشخيص فقط ولا تُرفع إلى حزمة الأسانيد.
- أي حالة غير معروفة أو تعذر قراءة manifest يجب أن يفشل مغلقاً ولا يتحول إلى fallback متساهل.
- المسارات في manifest نسبية إلى جذر النسخة المنشورة من هذا المستودع، ولا تمنح أي صلاحية كتابة.

المخطط: `schemas/corpus-manifest-v1.schema.json`.
