# API

واجهة استهلاك مستقلة لـ Saudi Legal Corpus.

الهدف أن تتمكن المشاريع الخارجية مثل QADA وAgent OS من القراءة أو التحقق عبر API دون دمج المستودعات أو خلط قواعد البيانات.

المبدأ:
- القراءة عامة للمحتوى المنشور.
- أي تحديث آلي يجب أن يمر بالتحقق وسياسة المصادر قبل اعتماده.
- API لا يضيف تفسيرًا قانونيًا إلى النص الرسمي.
